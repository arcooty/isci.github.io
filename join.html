Oyuna katıl

Java veya Bedrock bağlantı bilgilerini seç.

Sunucu adresi

oyna.robsarcade.online

Desteklenen Java sürümleri: 1.9 - 26.3. Önerilen sürüm: 26.3.

  1. Çok Oyunculu'yu aç

    Minecraft Java Edition ana ekranından Çok Oyunculu bölümüne gir.

  2. ArcaDe Craft'ı ekle

    Sunucu Ekle'ye bas. Sunucu adına ArcaDe Craft, sunucu adresine oyna.robsarcade.online yaz ve kaydet.

  3. Lobide oyununu seç

    Sunucuya katıl, ilk girişte ekrandaki hesap yönergelerini tamamla. Pusuladan Survival veya açık olduğunda Rob's Village'ı seç. Skyblock yalnız beyaz listedeki test hesaplarına açıktır.

Sunucu adresi

bedrock.robsarcade.online

Port

6426

Desteklenen Bedrock sürümleri: 26.30 - 26.51. Önerilen sürüm: 26.51.

  1. Sunucular sekmesini aç

    Minecraft Bedrock'ta Oyna → Sunucular bölümüne gir. Sunucu Ekle seçeneğini bul.

  2. Adres ve portu yaz

    Adı ArcaDe Craft, adresi bedrock.robsarcade.online, portu 6426 olarak kaydet. Bir sunucu eklemek için Microsoft hesabınla oturum açman gerekebilir.

  3. Katıl ve oyununu seç

    Sunucuya katıldıktan sonra lobideki oyun menüsünü kullan. Mobil menülerden Survival'a veya açık olduğunda Rob's Village'a geçebilirsin. Skyblock şu anda beyaz listeli test erişimindedir.

Konsollarda özel sunucu ekleme seçenekleri cihaza göre değişebilir. Bu adımlar mobil ve Windows Bedrock için geçerlidir.
